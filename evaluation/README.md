# RAG for EO Evaluation

Prompts and questions used for the DARES'25 paper and the underlying thesis can be found at `prompt_generator/`.

## DARES'25

The subdirectory `DARES25/` contains all generated answers and evaluation code related to the paper: <https://dares25.github.io/papers/DARES25_paper_10.pdf>.

## Thesis

The subdirectory `thesis/` contains samples, prompts and evaluation results for the thesis this repo is based on. It can be found at <https://elib.dlr.de/216432/>.
